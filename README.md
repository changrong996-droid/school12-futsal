# 第12学校的五人制足球赛

一个像素风的三维立体模型，整个应用就是一个 HTML 文件。漂浮的小岛上有一块蓝色橡胶球场（可以切换场地材质）、一栋教学楼、坐满孩子和家长的看台，还有一个比赛引擎，会完整地踢完一场比赛：球员入场、热身、列队、上下两个半场、中场休息、全场结束、赛后握手，最后一起走回教学楼。

**在线体验：** https://changrong996-droid.github.io/school12-futsal/

使用 three.js r160，通过 import map 从 jsDelivr 加载。不需要构建：`index.html` 就是整个应用。界面为简体中文，使用系统自带的中文字体（苹方、冬青黑体、微软雅黑、Noto Sans CJK），不下载任何网络字体。

## 内容

- **渲染：** 正交相机以 31° 俯角、45° 方位角渲染到低分辨率画布（桌面端宽 320 像素，手机端 240 像素），并带深度纹理。后处理会在深度突变处描黑边，把每个像素对齐到固定的 32 色调色板，再用 `image-rendering: pixelated` 放大显示。
- **场景：** 40×20 米的球场，四周是带门的铁丝网。场地有完整的五人制标线、3×2 米的条纹球门和球网、两队替补席和记录台。三面是看台。教学楼有门廊、球队进出的大门、挂钟、旗杆、“第12学校”校牌和一块 64×32 的记分牌。周围还有游乐场、自行车棚、小仓库、篮球架、小卖部、树木、球童、摄影师、保安和四座照明灯塔。每次旋转视角后，离镜头最近的那一侧围网和看台会被切掉。
- **人物：** 所有人共用一套骨骼（髋、胸、头、上臂、前臂、大腿、小腿），由一个 InstancedMesh 绘制全部身体部件，看台观众用同一套骨骼的精简版本。每个人都有独立的头、几种发型和发色、躯干、短裤、袜子和球鞋、手臂，身高和体型略有不同，孩子明显比大人矮小。球衣有撞色袖子和肩部饰条，背后印有号码（放大后可以看清），每队一名队长戴袖标，守门员穿不同颜色的长袖球衣、长裤并戴手套。裁判和记录员穿天蓝色上衣配黑色袖子，与任何球队和场地颜色都不同。动作包括跑步（摆臂、屈膝、上下起伏）、站立时的轻微晃动、踢球（支撑脚加摆腿）、守门员的预备蹲姿和鱼跃扑救、进球后举手庆祝和跪地滑行、握手、替补席和看台上的坐姿，以及观众各自错开节奏的鼓掌、跳起和挥手。摄影师拿着带闪光灯的相机（单膝跪地拍摄），保安戴帽子穿反光背心，球童穿橙色号码背心，小卖部店员系着围裙。
- **比赛引擎：** 四支原创球队（河畔水獭队、山岗彗星队、枫林狐狸队、北门猫头鹰队），每队九名球员，采用 1-2-1 阵型。比赛中会滚动换人。出界后以边线球、角球、球门球（守门员手抛或传出）和任意球恢复比赛。一支球队第 6 次及之后的每次犯规都判罚 10 米球，禁区内犯规判罚 6 米点球。皮球物理包含二次空气阻力、弹跳、滚动阻力和由滑动转为滚动的过程。传球和挑传的力度由解析求解器计算。人物由生成器协程驱动，并用 A* 在岛上寻路。
- **记分牌：** 64×32 像素放不下清晰的汉字，所以记分牌上用拼音缩写的队名代码（SHT 水獭、HXG 彗星、HLI 狐狸、MTY 猫头鹰）、比分、比赛时间、半场和全队犯规点；页面左上角的计分条显示中文队名。

## 操作

| 控件 | 作用 |
|---|---|
| ⟲ ⟳（画面上） | 以 90° 为单位旋转视角 |
| + −（画面上） | 放大、缩小 |
| 对阵 | 选择主队和客队，或点“随机对阵”（会开始一场新比赛） |
| 比赛时长 | 两个半场大约占用的现实时间：4、8、12 或 20 分钟（每个半场的比赛时间为 20 分钟） |
| 场地材质 | 橡胶、沥青、人造草或木地板。会改变球场外观和皮球物理（弹跳、滚动、滑动）。在木地板上球员会有点打滑 |
| 时段 | 白天、黄昏或夜晚。改变天空和光照；黄昏和夜晚会打开照明灯和教室的灯 |
| 镜头 | 转播跟随、全场或特写 |
| 观众互动 | “射门！”“横传”“长传”会影响持球球员的下一个动作 |
| 点击球场 | 放置一个标记，下一脚传球会传到那里 |
| 播放 | 暂停/继续、1× 或 2× 速度、解说开关、重新开始 |
| 声音 | 开启/关闭声音（默认静音）和音量滑块；画面右上角的喇叭按钮也可以开关 |

测试用的网址参数：`?speed=20`（模拟加速）、`len=4|8|12|20`、`surface=asphalt`、`tod=night`、`cam=tv`、`home=0&away=3`。

## 声音

默认静音。点击“开启声音”（或画面右上角的喇叭）后才会启动音频（浏览器要求用户先点一下），旁边的滑块调音量。暂停比赛时声音一起暂停，切到别的标签页时也会暂停。

- **声音导演：** 比赛引擎在发生事件的那一刻把事件交给声音导演：开球、传球和射门（按力度区分）、停球、弹地、地面滚动、抢断、犯规、扑救（接住 / 托出 / 封堵）、击中门柱或横梁、射偏、进球、球撞网和围网、滑跪庆祝、中场两声哨、终场三声哨。同一帧里产生的所有事件都在 Web Audio 时钟的同一个时间点排程，所以声音和画面落在同一帧；倍速（1×/2×）和暂停都会被尊重。
- **球声按场地区分：** 橡胶（闷）、沥青（脆亮）、人造草（软、带草声）、木地板（空心的木头声，混响更多），弹地和滚动声也随场地变化。
- **分层人群：** 常驻低语 + 紧张层（球离球门越近越紧张，平滑升降）+ 惊叹 / 叹息（射偏、扑救、中柱）+ 进球欢呼（主队进球更响，客队进球时主队看台会叹气）+ 掌声和口哨。每块看台是一路独立的声音，按看台在画面里的位置做立体声，随镜头旋转而移动；被切掉的近侧看台会变小声。新反应会交叉淡入并压下旧反应，裁判吹哨时人声自动降低一点。每次播放都会随机挑版本、微调音高和起始点，避免听出重复。
- **合成与录音（按盲听结果定稿）：** 每一层声音单独选择来源。裁判哨声（犯规短哨、开球长哨、中场两声、终场三声）、射偏后的叹息、进球欢呼用少量 CC0 录音（`crowd-cc0.mp3`，约 0.4 MB）；看台常驻低语、紧张层、惊叹、掌声、所有球声和看台上个人喊“加油”都在浏览器里用 Web Audio 程序合成（合成在 Web Worker 里完成，不卡画面）。如果录音文件加载失败，这几层会自动退回合成声。
- **试听页：** [`sound-test.html`](sound-test.html) 可以逐类盲听每种声音的 2–3 个版本（A/B/C）。盲听已经完成，游戏按结果定稿；因为精简后的录音文件不再包含底噪、惊叹和掌声录音，试听页里这几类的“录音”版本现在会退回合成声。

测试用的网址参数：`crowd=rec|hybrid|synth`（不用定稿配置，改成旧的整体模式：人群全录音 / 底噪合成+反应录音 / 全部合成；注意录音文件现在只含哨声、叹息和欢呼，缺的层会退回合成）、`whistle=synth|rec`、`seed=N`（固定随机种子）。
